# Premium Purple Dark — заключительный аудит

## Исправления

- При ширине окна до 650 CSS px доступна панель папок и языка с кнопкой
  в навигации, закрытием по Escape, фону, выбору папки и уходу фокуса.
- Увеличена ширина фильтра статуса, сокращена подпись ошибки в фильтре прокси;
  длинные заголовки переносятся, пагинация компактно располагается в две строки.
- Фокус вложенных диалогов изолирован через inert. У заголовков уникальные
  aria-labelledby, при закрытии восстанавливается предыдущий доступный фокус.
- Формы диалогов предотвращают неявную навигацию/GET-отправку по Enter.
  Существующие кнопки и их обработчики сохраняются.
- Ошибки становятся видимыми и фокусируемыми; поздний ответ закрытого диалога
  не перехватывает фокус. Escape учитывает уже закрывающиеся inert-окна.
- Поиск, журнал, языки и выбор страницы имеют локализованные aria-label.
  Поля импорта текста и cookies имеют доступные имена.
- История различает отсутствие записей и отсутствие совпадений поиска.

Палитра и токены предыдущих этапов, все 27 полей редактора, 14 столбцов таблицы,
API, форматы хранения и алгоритмы работы браузера сохранены. Пользовательские
профили, cookies, токены и локальные конфигурации не читались и не изменялись.

## Автоматические проверки

GitHub Actions (`UI checks`) запускает все `tests/*.test.js`, прежнюю проверку
`test_profile_ui.cjs`, синтаксис JavaScript, тесты CSS-токенов/предпросмотра,
полный существующий Python-набор и compileall на Windows/Python 3.12.
Node.js — 24. Результат привязан к проверяемому Git-коммиту.

Первый полный Windows-прогон выполнил 324 теста и выявил 8 сравнений
короткого пути RUNNER~1 с его полным эквивалентом. Для тестов задаётся
канонический временный каталог в RUNNER_TEMP. Утверждения тестов и
производственная логика работы с путями не ослаблялись.

Добавлены сценарии компактной навигации, фокуса/модальности, уникальных
заголовков, отмены неявного submit, видимости ошибок и позднего ответа.
Также включены ранее не запускавшиеся JS-тесты desktop Escape и презентации
профиля; последнему добавлена зависимость icons.js, используемая интерфейсом.

## Границы проверки

Локальный запуск процессов недоступен из-за ошибки рабочего окружения.
Была подготовлена автономная копия текущих CSS/JS с синтетическими профилями,
но её открытие отклонено политикой браузера, разрешающей только HTTP/HTTPS.
Обход ограничения не выполнялся. Новые реальные скриншоты, визуальная
плавность и физическое масштабирование Windows 100/125/150/200% не проверены.

Не выполнены реальные запуски Chrome с пользовательскими сессиями, вход в X,
вызовы провайдера прокси, авторизованный импорт Dolphin, установка обновления
и перезапуск установщика. Эти сценарии требуют desktop-окружения и внешних
сервисов. Автотесты API используют изолированные временные данные.

Это техническая подготовка к финальной визуальной приёмке; подтверждение
готовности установщика и внешних интеграций требует перечисленных проверок.
