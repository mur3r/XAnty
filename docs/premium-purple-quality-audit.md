# Premium Purple Dark — заключительный аудит

## Исправления

- При ширине окна до 650 CSS px доступна панель папок и языка с кнопкой
  в навигации, закрытием по Escape, фону, выбору папки и уходу фокуса.
- Увеличена ширина фильтра статуса, сокращена подпись ошибки в фильтре прокси;
  длинные заголовки переносятся, пагинация компактно располагается в две строки.
- Фокус вложенных диалогов изолирован через inert. У заголовков уникальные
  aria-labelledby, при закрытии восстанавливается предыдущий доступный фокус.
- Формы диалогов предотвращают неявную навигацию/GET-отправку по Enter.
  Существующие кнопки и их обработчики сохраняются.
- Ошибки становятся видимыми и фокусируемыми; поздний ответ закрытого диалога
  не перехватывает фокус. Escape учитывает уже закрывающиеся inert-окна.
- Поиск, журнал, языки и выбор страницы имеют локализованные aria-label.
  Поля импорта текста и cookies имеют доступные имена.
- История различает отсутствие записей и отсутствие совпадений поиска.
- Имя профиля, логин, папка и теги получили больше места; метаданные
  располагаются в две строки, полное название доступно во всплывающей подсказке.
- На узких окнах восстановлены кнопки обновлений и закрытия всех браузеров.
  Они располагаются во второй строке нижней панели и остаются доступными.

Палитра и токены предыдущих этапов, все 27 полей редактора, 14 столбцов таблицы,
API, форматы хранения и алгоритмы работы браузера сохранены. Пользовательские
профили, cookies, токены и локальные конфигурации не читались и не изменялись.

## Автоматические проверки

GitHub Actions (`UI checks`) запускает все `tests/*.test.js`, прежнюю проверку
`test_profile_ui.cjs`, синтаксис JavaScript, тесты CSS-токенов/предпросмотра,
полный существующий Python-набор и compileall на Windows/Python 3.12.
Node.js — 24. Результат привязан к проверяемому Git-коммиту.

Первый полный Windows-прогон выполнил 324 теста и выявил 8 сравнений
короткого пути RUNNER~1 с его полным эквивалентом. Для тестов задаётся
канонический временный каталог в RUNNER_TEMP. Утверждения тестов и
производственная логика работы с путями не ослаблялись.

Добавлены сценарии компактной навигации, фокуса/модальности, уникальных
заголовков, отмены неявного submit, видимости ошибок и позднего ответа.
Также включены ранее не запускавшиеся JS-тесты desktop Escape и презентации
профиля; последнему добавлена зависимость icons.js, используемая интерфейсом.

## Визуальная проверка на Windows

Добавлен отдельный необязательный Playwright-набор. Он запускает настоящий
HTML/CSS/JavaScript XAnty в Chromium на Windows, а API и WebSocket заменяет
loopback-сервером с синтетическими данными. Импорты хранилища приложения,
пользовательские каталоги и внешние сервисы в стенде отсутствуют.

Матрица: 2 темы × 3 языка (ru/en/uk) × 5 размеров окна:
1440×900, 1280×720, 900×650, 520×740 и 900×500 CSS px. Device scale factor:
1, 1.25, 1.5 и 2. Это проверка растеризации Chromium; она не подменяет
физическое переключение масштаба Windows или проверку WebView2.

Проверяются переполнения страницы и диалогов, ширина выбранных подписей
фильтров, видимость нижних действий, 27 полей редактора, фокус и Escape.
Расширенные сценарии охватывают поиск, пагинацию, выделение всех 120 совпадений,
массовое редактирование, контекстное меню, состояния запуска/остановки и прокси,
ошибку сохранения, создание папки, Dolphin, передачу/импорт пакета, все
14 настроек столбцов, настройки браузера, историю, корзину, cookies, отчёт,
инструменты, CPU/RAM и экран заметок версии.

Отдельные сценарии проверяют 5000 синтетических профилей (50/250 строк в DOM,
поиск последнего профиля) и изменение prefers-reduced-motion во время работы.
Выбор файла проверяется в пакетном импорте и cookies: локализованные подписи,
показ/сброс имени и клавиатурный фокус. Нативный input и его обработчики сохранены.
Убраны дубли описаний мониторинга/инструментов и текущей версии обновления.

Снимки перечисленных окон действительно созданы и просмотрены. Исправления
читаемости метаданных профиля и скрытых действий узкой нижней панели основаны
на этих снимках. Сервер и все снимки содержат только тестовые данные.

Полный набор: 57 JavaScript-тестов, прежняя проверка profile_ui, 3 проверки
CSS/предпросмотра, 327 Python-тестов (включая 3 проверки стенда), синтаксис
JS/Python, 30 визуальных сочетаний и 2 дополнительных браузерных сценария.
Точный результат каждого запуска привязан к SHA в GitHub Actions, а снимки,
report.json и лог стенда сохраняются в артефакте xanty-visual-audit на 7 дней.
Зависимости requirements-visual.txt не входят в приложение и установщик.

Для воспроизведения в отдельном окружении разработки:

```powershell
python -m pip install -r requirements-visual.txt
python -m playwright install chromium
python tools/visual_audit.py
```

## Границы проверки

Локальный запуск процессов рабочего окружения недоступен. Попытка открыть
нативный Python через разрешённый интерфейс управления компьютером не получила
подтверждения до истечения тайм-аута. Обход ограничений не выполнялся.

Не подтверждены запуск установленного XAnty через WebView2, физический Windows DPI,
плавность на пользовательском оборудовании, реальные Chrome-сессии, вход в X,
вызовы провайдера прокси, авторизованный импорт Dolphin, установка обновления
и перезапуск установщика. Их интерфейс проверяется с синтетическими ответами;
это не проверка работы внешних интеграций. Автотесты Python/API используют
изолированные временные данные.
