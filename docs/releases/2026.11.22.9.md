# XAnty: установщик и обновление при запуске

- Перед загрузкой рабочего пространства программа проверяет GitHub Releases при каждом запуске.
- Новая версия скачивается, проверяется по SHA-256, устанавливается и запускается без дополнительных нажатий.
- При отсутствии сети или ошибке загрузки запускается установленная версия.
- После замены EXE помощник ждёт готовности нового сервиса; при сбое выполняется откат. Неудачная версия не вызывает бесконечного цикла перезапусков.
- Установщик XAnty-Setup.exe устанавливает программу для текущего пользователя, создаёт ярлык и содержит официальную пару Chrome for Testing / ChromeDriver.
- Если WebView2 отсутствует, установщик запускает подписанный загрузчик Microsoft; для этого нужен Интернет.
- Профили и настройки хранятся отдельно от файлов программы и сохраняются при обновлении и удалении приложения.
- Загрузка изменений в main запускает тесты, сборку EXE и установщика, назначение новой версии и публикацию полного релиза.

Старую версию нужно один раз заменить этой сборкой. Автоматическая установка при запуске действует начиная с неё.
