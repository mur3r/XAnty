# XAnty 2026.11.22.5

- Логотип EXE, окна и интерфейса заменён предоставленным изображением; убрано большое пустое пространство старого значка.
- Нативное окно появляется до подготовки сервиса и профилей. Инициализация выполняется в фоне, ошибки остаются видны после загрузки WebView2, закрытие окна во время запуска отменяет последующую навигацию.
- Внутренний объект окна скрыт от обхода JavaScript API: исключены обращения к нативным свойствам Windows из потока инициализации интерфейса.
- Подключён публичный канал обновлений mur3r/XAnty. Перезапуск однофайлового EXE выполняется с новым окружением PyInstaller.

## Проверки

- 85 Python-тестов, проверки поведения интерфейса на Node.js, компиляция Python и синтаксис JavaScript прошли.
- При 144 тестовых профилях и искусственной задержке подготовки 8 секунд окно появилось через 2,11 секунды, сервис стал готов через 12,12 секунды. Все 38 проверок отклика окна успешны; Windows не считала окно зависшим.
- Ранняя ошибка сервиса проверена на настоящем WebView2: сообщение остаётся на экране.
- [Сборка релиза в GitHub Actions](https://github.com/mur3r/XAnty/actions/runs/44978183573) завершилась успешно.
- Реальная установка официального скачанного EXE проверена на отдельной копии программы с тестовыми данными: SHA-256, замена файла, автоматический перезапуск, резервная копия и файлы профиля сохранены. Для вызова установки использовались локально подготовленные метаданные будущей версии, указывающие на тот же официальный EXE `.5`.

Первую подключённую сборку следует установить вручную. Дальнейшие версии обнаруживаются через GitHub Releases; неподключённые старые EXE этот релиз автоматически не найдут.
