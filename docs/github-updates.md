# Установка и обновления XAnty

## Для пользователя

Скачайте `XAnty-Setup.exe` из [последнего релиза](https://github.com/mur3r/XAnty/releases/latest).
Установщик работает для текущего пользователя без прав администратора. Он устанавливает XAnty,
официальные Chrome for Testing и ChromeDriver, создаёт ярлыки и запись удаления приложения.
Если Microsoft WebView2 отсутствует, подписанный загрузчик Microsoft установит его; для этого нужен Интернет.

Программа находится в `%LOCALAPPDATA%\Programs\XAnty`, настройки — в `%LOCALAPPDATA%\XAnty`.
При первой чистой установке рабочая папка создаётся в `%LOCALAPPDATA%\XAnty\data`.
Существующая выбранная рабочая папка сохраняется. Собственные Bro/Drivers в ней имеют приоритет
над браузером из установщика. Профили, cookies и настройки не входят в установщик и не удаляются
при удалении приложения.

## При каждом запуске

1. Появляется стартовое окно. До запуска рабочего пространства XAnty проверяет опубликованный GitHub Release.
2. Если версия новее, программа скачивает только `XAnty.exe`, проверяет размер, формат EXE и SHA-256 из GitHub.
3. Помощник дожидается завершения старого процесса, сохраняет `XAnty.exe.previous`, заменяет EXE и запускает его.
4. Новый процесс подтверждает готовность сервиса. Если он не запускается, помощник восстанавливает предыдущий EXE.
5. Пользователь работает с программой. Его данные остаются в прежней рабочей папке.

Интернет недоступен или скачивание не удалось — запускается установленная версия. После неудачной
установки та же версия повторно автоматически не устанавливается, чтобы не получить цикл перезапусков.
Повторная ручная установка остаётся доступна в разделе «Обновления». Проверка при запуске выполняется
даже при свежем суточном кэше; проверка во время работы остаётся фоновой и не прерывает работу с профилями.

Ранние версии, в которых ещё нет автоматической установки при запуске, нужно один раз заменить
новой сборкой через установщик.

## Для разработчика

Загрузите проверенные изменения в `main`. Workflow `.github/workflows/release.yml` автоматически:

- выполняет Python-тесты, проверки интерфейса и синтаксиса;
- выбирает номер версии больше последнего опубликованного, даже если номер в исходниках не менялся;
- собирает однофайловый EXE и установщик с официальным браузером;
- проверяет установку и удаление на чистой временной папке;
- загружает `XAnty.exe`, `XAnty-Setup.exe` и `SHA256SUMS.txt` в черновик;
- сверяет размеры и SHA-256 загруженных файлов и публикует готовый релиз.

Ручное создание тега или публикация черновика больше не нужны. При ошибке тестов/сборки предыдущий
релиз остаётся последним. Сборки выполняются последовательно; устаревший коммит не публикуется
поверх более нового состояния main. Запуск workflow вручную также доступен для main.

Локальная сборка: `python tools/build_windows.py --onefile --dist-dir dist/release`,
затем `python tools/build_installer.py` (нужен Inno Setup 6/7).
Исходники и сборки не должны включать локальные аккаунты, профили и реквизиты прокси.
