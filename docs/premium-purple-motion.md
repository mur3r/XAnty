# Premium Purple — анимации

`motion.css` подключается последним, `motion.js` — до остальных скриптов.
Эффекты используют существующую палитру и кривые ускорения. Основные длительности:
150 мс для меню и нажатия, 180 мс для переходов, 160 мс для закрытия,
220 мс для появления приложения. Новых зависимостей нет.

Разделы меняют только прозрачность: это сохраняет привязку фиксированных меню
к окну. Окна, меню и уведомления используют небольшие transform и opacity.
Переключатели, кнопки и существующие индикаторы занятости дают обратную связь
без дополнительной анимации строк таблицы.

`Motion.enter` снимает временные классы после animationend/animationcancel.
`Motion.exit` сразу устанавливает inert и aria-hidden; удаление завершается
после анимации с коротким резервным таймером. При быстром закрытии берётся
текущая прозрачность, чтобы отмена входа не давала вспышку. Диалог помечается closed сразу,
его onClose и восстановление фокуса выполняются синхронно. Повторное открытие
обновлений и поздние ответы API учитывают closed и не ждут визуального удаления.

Прогресс сопоставляется по data-progress-id. При замене HTML сохраняется старый
inline-процент; новая полоса анимируется через scaleX от предыдущей длины до
целевой. Нет requestAnimationFrame, чтения геометрии и обхода строк таблицы.
Сброс этапа, новая задача и неопределённый прогресс не интерполируются.

prefers-reduced-motion отключает анимации и переходы. Изменение настройки
немедленно завершает текущие эффекты; прокрутка к инструментам также учитывает
системную настройку. Закрытие и бизнес-действия не зависят от окончания эффекта.

Проверки покрывают события завершения/отмены, резервное удаление, доступность,
смену системной настройки, прогресс и синхронное подтверждение закрытия.
В текущем окружении недоступен локальный desktop-запуск; визуальную плавность
в WebView2 и реальные внешние операции нужно проверить в desktop-сборке.

Ветка редизайна и pull request запускают лёгкие UI-проверки в GitHub Actions:
JavaScript-регрессии, синтаксис, CSS-токены и автономный предпросмотр.
