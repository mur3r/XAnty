# Premium Purple — первый этап

Общие токены, темы и компоненты находятся в
`xgenius/web/static/design-system.css`. Файл подключён после `style.css`,
который сохраняет разметку и размеры существующих страниц.

| Назначение | Переменная | Тёмная тема |
| --- | --- | --- |
| Основной фон | `--color-bg` | `#0C0A14` |
| Боковая панель | `--color-sidebar` | `#171225` |
| Карточки | `--color-card` | `#241C38` |
| Акцент | `--color-accent` | `#9165F7` |
| Светлый акцент | `--color-accent-light` | `#B89AFF` |
| Тёмный акцент | `--color-accent-dark` | `#673BC9` |
| Основной текст | `--color-text` | `#F4F0FF` |
| Вторичный текст | `--color-text-secondary` | `#A59BB9` |

Светлая тема задаётся существующим `data-theme="light"`: нейтральные
сиреневые фоны, белые карточки и тёмный фиолетовый акцент. Текст основной
кнопки тёмный на светло-фиолетовом фоне в тёмной теме и белый на насыщенном
фиолетовом в светлой — это сохраняет читаемость обеих комбинаций.

Для новых элементов используйте `--space-*` (шаг 4 px), `--radius-*`,
`--font-*`, `--shadow-*`, `--duration-*` и `--ease-*`. Старые переменные
`--bg`, `--surface`, `--accent` и другие остаются совместимыми псевдонимами.

Системные шрифты работают без загрузок и поддерживают русский, английский
и украинский языки. У состояний hover, focus, active и disabled единый
стиль. `prefers-reduced-motion` отключает анимации и переходы.

Идентификаторы, обработчики событий, структура таблиц и модальных окон
сохранены. Ротация прокси входит в этот же коммит; оформление не меняет
условия запуска сетевых запросов. В сборку EXE новый CSS включается
существующим правилом упаковки всей папки static.
