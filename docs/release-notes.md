# Список изменений после обновления

После запуска новой версии XAnty разворачивает окно и показывает экран «Что нового».
Его содержимое берётся из `xgenius/web/static/release-notes.md`, который входит в EXE
вместе с остальными файлами интерфейса. Интернет для просмотра не нужен.

Перед каждым выпуском обновляйте этот файл: перечисляйте конкретные изменения для
пользователя, используйте заголовки Markdown и пункты списка. Номер версии берётся
из программы, в том числе после автоматического назначения версии в GitHub Actions.

Закрытие кнопкой, крестиком или Escape сохраняет просмотренную версию в настройках
программы. При обычном перезапуске экран повторно не появляется. Новая версия, а
также первый запуск программы показывают его автоматически. Повторный просмотр:
«Обновления» → «Что нового».
