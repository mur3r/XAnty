# Описание обновлений

`xgenius/web/static/release-notes.md` содержит только изменения текущего выпуска.
При первом запуске новой версии открывается именно этот список. Закрытие сохраняет
просмотренную версию; при следующем запуске список больше не мешает работе.

Полная история находится в «Настройки XAnty» → «История обновлений».
Кнопка с шестерёнкой в левой панели открывает настройки на всех размерах окна.
История хранится в `xgenius/web/static/release-history.json` и доступна без интернета.

Перед сборкой `tools/prepare_release.py` получает все страницы опубликованных
стабильных GitHub Releases и обновляет историю внутри сборки. Предыдущий выпуск
автоматически попадает в неё при следующем обновлении. Старые накопительные
описания разделяются: повторяющийся список более ранних изменений убирается из
нового пункта истории. Черновики и предварительные выпуски в неё не входят.

Перед публикацией заменяйте содержимое release-notes.md новым описанием, а не
добавляйте его к старому. Номер установленной версии берётся из программы после
автоматического назначения в GitHub Actions. Для текста поддерживаются заголовки,
обычные абзацы и списки; HTML показывается как текст.
