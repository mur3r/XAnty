# Premium Purple — экран профилей

Оформление экрана изолировано в `profiles-screen.css`, визуальные помощники —
в `profiles-screen.js`. Палитра и глобальный `design-system.css` сохранены.

- Карточки статистики, аватары, теги, состояния запуска и остановки, прокси
  и геолокация используют существующие токены.
- Поиск и фильтры работают вместе с четырьмя вариантами локальной сортировки.
  Избранные сверху — исходный вариант по умолчанию.
- Для длинных списков доступны прежние размеры страниц, переход по номеру,
  закреплённые заголовки, имя и действия. На узком экране имя прокручивается.
- Все 14 столбцов, их видимость и порядок сохранены. В DOM создаётся только
  текущая страница, максимум 250 строк. Фильтрация при отрисовке выполняется
  один раз; форматирование времени переиспользует Intl.NumberFormat.
- Обновление списка сохраняет прокрутку и открытое меню. Переход страницы
  возвращает к её началу. Индикатор загрузки появляется с небольшой задержкой,
  чтобы быстрые запросы не создавали мерцание. При ошибке остаются последние данные.
- Пустой список, пустая папка и отсутствие совпадений имеют отдельные состояния.

Алгоритмы запуска браузера, серверные действия и состав массовых операций
не изменены. Короткие переходы используют общие длительности и отключаются
через существующий prefers-reduced-motion.
