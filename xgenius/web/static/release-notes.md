## HTTP и SOCKS5

- Добавлены проверка и запуск профилей через SOCKS5 с логином и паролем. Для ранее сохранённых строк тип прокси определяется автоматически.
- Проверка IP поддерживает IPv4/IPv6 и резервные сервисы проверки через тот же прокси.
- Исправлено отображение города рядом со страной и регионом. Ошибки проверки переведены на язык интерфейса.

## Ротация мобильных прокси

- Увеличено ожидание ответа провайдера и восстановления связи после смены IP.
- Программа учитывает ответы провайдера с result: failure и не показывает их как успешную ротацию.
- После одного запроса ротации повторяется только проверка IP; сам запрос смены IP не дублируется.
