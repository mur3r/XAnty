## Полная передача профилей

- Передача профилей теперь по умолчанию сохраняет названия, прокси и их пароли, ссылки ротации, настройки браузера, папки, теги, заметки, cookies и сохранённые вкладки.
- Исправлен выбор режима в обоих окнах экспорта: сокращённый шаблон без данных профиля включается только вручную.
- В описании режима явно указано, что входит в файл передачи.

## Последнее обновление и история

- При запуске после обновления показываются только изменения установленной версии.
- Предыдущие выпуски доступны в «Настройки XAnty» → «История обновлений», в том числе без интернета.
- Настройки можно открыть кнопкой с шестерёнкой в левом меню.
