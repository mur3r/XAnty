## Свои цвета интерфейса

- В настройках XAnty можно выбрать акцент, основной фон, фон боковой панели и карточек, а также основной и вторичный текст.
- Палитры светлой и тёмной тем сохраняются отдельно и применяются после перезапуска.
- Изменения видны сразу. Сохраните их кнопкой «Сохранить»; отмена или закрытие окна возвращают прежние цвета.
- Для каждой темы есть сброс к стандартной палитре.

## Сворачиваемая панель папок

- Кнопка панели папок в левом меню сворачивает её и освобождает место для таблицы профилей.
- Состояние панели запоминается. На узких окнах остаётся выдвижная панель с папками и выбором языка.

## Папка для файла передачи

- При передаче всех или выбранных профилей можно указать папку, где будет сохранён файл .xanty.
- В приложении доступно окно выбора папки Windows; путь также можно ввести вручную.
- Последняя папка запоминается. Пустое поле возвращает обычное скачивание.
- После создания файл проверяется и сохраняется в выбранной папке. В отчёте показан полный путь к готовому файлу.
