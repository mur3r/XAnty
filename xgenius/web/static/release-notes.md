## Исправление запуска профилей через прокси

- Устранено повторное использование Chrome старого обработчика авторизации прокси. Каждый запуск получает новый служебный обработчик, поэтому сохранённые браузером старые логин, пароль или порт больше не вызывают ложную ошибку 407.
- Исправлен случай, когда проверка HTTP-прокси проходит, а запуск профиля завершается ошибкой Chrome proxy authentication failed (407). Логин и пароль теперь отправляются провайдеру сразу при каждом соединении, как при проверке прокси, без зависимости от браузерного обмена авторизацией.
- Каждый профиль получает отдельный локальный адаптер с временными данными доступа. Данные авторизации провайдера не передаются сайтам. При недоступности прокси прямое соединение не используется.
- Можно вводить IP:порт:логин:пароль без префикса, а также http://IP:порт:логин:пароль и socks5://IP:порт:логин:пароль. Явно указанный HTTP больше не заменяется автоматически на SOCKS5.
- Перед публикацией настоящий Chrome проверяется на искусственном HTTPS-прокси: воспроизведение прежнего сбоя, запуск и повторный запуск профилей, обычный и headless-режим, проверка IP и открытие страницы.
