## Исправление закрытия браузера после запуска

- Исправлен вылет Chromium 158 с ошибкой invalid session id при первоначальной настройке поиска. Внутренние страницы Chrome теперь открываются в обычной фоновой служебной вкладке без переключения пользовательской страницы.
- Фоновые веб-проверки продолжают работать в скрытых вкладках там, где они поддерживаются.
- Перед выпуском проверяются настоящие Chrome и ChromeDriver из установщика: сохранение пользовательской вкладки и работа браузера дольше 20 секунд в обычном и headless-режиме.
