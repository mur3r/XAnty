## User-Agent профиля

- Кнопка UA в строке профиля копирует его User-Agent. В меню действий доступно окно просмотра с копированием и переходом к редактированию.
- Для открытого профиля читается фактический User-Agent из браузера; для закрытого показывается значение следующего запуска.
- В редактор добавлены автоматический режим, генератор по установленному Chromium и ручной ввод с проверкой совместимости версии и формата Windows.
- Генератор использует реальную версию выбранного ядра. При одинаковой версии и ОС корректные User-Agent могут совпадать.
- Сохранены собственные User-Agent Client Hints Chromium: настройка совместимости больше не обнуляет их через подмену UA.
