## Управление прокси

- В редакторе профиля появился выбор типа: Авто, HTTP, HTTPS и SOCKS5. Адрес и реквизиты сохраняются отдельно для каждого профиля; тип виден в таблице рядом с адресом.
- Добавлены HTTPS-прокси с шифрованием соединения до прокси и обязательной проверкой сертификата, включая авторизацию логином и паролем. Поддержка SOCKS5 с авторизацией сохранена.
- Предупреждение «Общий IP» показывает, у скольких других профилей совпадает проверенный выходной IP. Сравнение охватывает все папки и страницы. Результат основан на последних успешных проверках и обновляется при повторной проверке.
- Перед ротацией выполняется свежий замер IP. Подтверждённая смена показывается как «старый IP → новый IP»; прежний или недоступный IP обозначается отдельно. Повторные проверки не отправляют повторный запрос на ротацию.
- Добавлены проверки TLS-соединения, передачи данных, отказа при недоверенном сертификате, сохранности реквизитов и предупреждений о совпадении IP. Новые элементы переведены на русский, английский и украинский языки.
