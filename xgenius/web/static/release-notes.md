## Исправлено скачивание профилей

- Исправлена передача больших файлов .xanty в Windows: скачивание теперь использует отдельные неизменяемые блоки данных, исключая искажение байтов при асинхронной отправке.
- Скачивание с продолжением сохраняет точные байты архива.

## Проверка файлов передачи

- Готовый файл .xanty теперь повторно читается целиком: программа проверяет ZIP, CRC и SHA-256 каждой записи перед сообщением об успешном экспорте и скачиванием.
- Если проверка не пройдена, повреждённый результат удаляется. В процессе виден отдельный этап проверки.
- При загрузке файла сверяется его размер. После загрузки показывается этап проверки целостности.
- Для повреждённых и неполных пакетов отображается понятное сообщение на языке интерфейса с инструкцией повторить передачу.
