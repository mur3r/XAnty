XAnty profile manager

Add or import an account, then use Open to launch its browser. Select multiple accounts to open or close them together. Use Bulk edit to change their folder or proxy assignment. The Load tab shows resource use, and Monitor shows runtime errors.

Folders in the account screen are saved between launches. Select profiles and click New folder to create a folder and add them in one step, or click Move selected to move them to an existing folder or No folder. Click a folder to see only its profiles. Rename changes its name for all assigned profiles; deleting a folder moves its profiles to No folder and does not delete browser data. Existing group labels appear as folders automatically.

Folders are on the left of the profile table. Search and status filters work on the selected folder. Bulk edit applies folder, proxy, X auto-login and only the browser settings you explicitly check; all changes are validated before any account is saved.

Each profile needs an HTTP proxy in host:port:user:password or http://user:password@host:port format (host:port also works without authentication). Click the pulse icon in its row to test the proxy and see its external IP. Opening a profile checks the proxy before Chrome starts and checks Chrome's external IP before X opens. A failed or mismatched IP stops launch; there is no direct fallback. Rotating proxies that change IP between these checks may need a sticky session. Existing account and browser files are preserved.

Use the X auto-login switch in each row, or select profiles and use X auto-login on/off. On launches the profile and attempts X sign-in with its existing session, token, or password. Off opens a blank browser without attempting X sign-in. Changes take effect the next time the profile opens. Existing profiles keep their previous default; new/imported profiles start with auto-login off.

Use the upload icon in a profile row to import X/Twitter cookies from a JSON or Netscape file (or paste its text). Close the profile before importing. The import replaces its saved cookies; they are applied when you next open it with X auto-login enabled. Use the download icon to export cookies from the open browser's current X tab, or from the last saved snapshot if that tab has no X cookies. Closing a profile or exiting the app also saves X cookies from its current tab. Cookies belong to the selected profile; keep exported files private. Exporting cookies is separate from copying the entire Chrome profile (local storage and other browser data).

Edit a profile to set browser language, IANA timezone and window width/height. Leave language/timezone blank to use the computer defaults. Changes apply next time the browser opens. The User-Agent is taken from the actual bundled Chrome version at each launch; the profile row shows Chrome's version and the User-Agent on hover. Old manually entered User-Agent values remain in account data but are no longer applied. Locale and timezone emulation apply to the tab managed by the application; newly opened tabs may use system defaults.

Import from Dolphin Anty: generate an API token in your Dolphin account and click From Dolphin. Enter one profile ID, click Preview one, then Import one. Its profile name, supported HTTP proxy, manual language/timezone, window size and X/Twitter cookies are copied into a new XAnty profile. Enable X auto-login, open it and verify the X session before checking the confirmation box and clicking Import remaining. Already imported Dolphin IDs are skipped. The import report can be downloaded. The API token and Dolphin profile password are not saved in XAnty.

Dolphin's remote cookie export requires a paid plan and cloud sync. If it is unavailable, the profile is imported without cookies and the report explains why. You can export cookies manually in Dolphin and import them with the cookie button in XAnty. SOCKS proxies, full browser fingerprint, other sites and local storage are not transferred; these require manual review. Auto-login stays off on imported profiles until you enable it.
