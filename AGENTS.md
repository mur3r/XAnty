# XAnty project instructions

This workspace is part of the XAnty project: https://github.com/mur3r/XAnty.

## Delivering fixes

- Publish requested fixes through GitHub so installed copies receive them through automatic updates. A standalone EXE attached in chat is not the normal delivery method.
- Base each release on the latest main branch, preserve unrelated local changes, and include regression checks and release notes for the fix.
- Use the existing release workflow to assign a newer version, build the EXE and installer, and publish verified release assets. Check that publication succeeded before reporting that an update is available.
- Keep local accounts, cookies, browser profiles, proxy credentials, and other private workspace data out of Git and release assets.
