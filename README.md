# XAnty — менеджер браузерных профилей

Первый этап переделки: удалены рассылка, парсинг групп, комментарии и их настройки. Пока используются прежние Chrome и ChromeDriver; полноценный антидетект ещё предстоит реализовать.

## Запуск

1. Установить Python 3.9+ и зависимости: `pip install -r requirements.txt`.
2. Положить совместимые `Bro/chrome.exe` и `Drivers/chromedriver.exe` в базовую папку.
3. Запустить `python main.py`; локальный интерфейс откроется по адресу http://127.0.0.1:8765/.
4. При первом запуске выбрать базовую папку. Существующие `accounts.json` и профили браузеров подхватываются автоматически; новые поля добавляются без ручной миграции. Прежние файлы рассылки остаются на диске без изменений.

Можно добавлять и импортировать аккаунты, открывать и закрывать браузеры, выводить окно на передний план, массово менять метку группы и прокси. Формат импорта: `username|auth_token|ct0_token|proxy|group`, по одному аккаунту на строку.

Профили Chrome изолированы по аккаунтам. Для каждого аккаунта доступны проверка прокси, импорт и экспорт cookies X/Twitter (JSON или Netscape), а также сохранение сессии при закрытии профиля. Импорт выполняется для закрытого профиля; для применения cookies при следующем открытии включите X auto-login. Экспорт cookies не копирует весь каталог Chrome с локальным хранилищем и расширениями.

## Настройки профиля

Настройки браузера задаются для каждого профиля: язык, IANA-часовой пояс и размер окна. User-Agent берётся из запущенного Chrome и автоматически меняется вместе с ним; старый случайный Chrome/128 больше не используется. Версия и UA видны в строке открытого профиля. Время и локаль через CDP применяются к управляемой вкладке; новые вкладки могут использовать системные значения.

## Менеджер и импорт из Dolphin

Папки показаны слева от таблицы профилей. Поиск, статусы и массовые действия работают по выбранным аккаунтам; массовое редактирование включает папку, прокси, автовход и настройки браузера.

Кнопка **Из Dolphin** переносит все доступные профили после ввода одного API-токена. ID профиля, предварительный одиночный импорт и ограничение 500 профилей больше не требуются: приложение обходит все страницы cursor API. Процесс выполняется в фоне, его прогресс и отчёт доступны в разделе **Переносы**. Можно остановить перенос; уже добавленные профили сохранятся. Повторный запуск пропускает ранее импортированные ID, совпадающие имена разных профилей получают отдельные внутренние идентификаторы.

Сохраняются исходные названия, папки, заметки, настройки, данные HTTP-прокси и доступные cookies всех сайтов. При наличии cookies авторизации X автовход включается автоматически. Токен API не сохраняется в настройках, пакетах и отчётах. Пароль для защищённых профилей можно указать в дополнительных настройках. Если API не отдаёт часть данных, запись профиля сохраняется с замечанием в отчёте.

По [официальной документации Dolphin](https://docs.dolphin-anty-cdn.com/index.html), удалённый экспорт cookies требует платного тарифа и включённой облачной синхронизации профиля. Полный отпечаток, local storage и расширения Dolphin этот API не экспортирует. XAnty использует свой Chrome, поэтому сохранение входа на каждом сайте нужно проверять.

## Язык и оформление

Интерфейс доступен на русском, английском и украинском языках. Переключатель расположен внизу боковой панели; выбор сохраняется между запусками EXE в `%LOCALAPPDATA%\XAnty\preferences.json`. Светлая и тёмная темы переключаются кнопкой с солнцем в левой панели. Основная тема — фиолетово-чёрная: боковая панель папок, таблица, фиолетовые кнопки запуска, массовые действия и отдельный список переносов. В качестве значка EXE, окна, вкладки и интерфейса используется изображение из `xgenius/web/static/assets/`.

## Проверка прокси, закрытие браузера и поиск

Рядом с адресом каждого прокси находится кнопка проверки. Во время запроса она показывает индикатор, при успехе — галочку и внешний IP, при ошибке — значок и описание. Повторные одновременные нажатия используют один запрос. После завершения можно запустить новую проверку.

После проверки рядом с IP отображаются флаг страны и регион, например **USA · Florida**. География определяется по проверенному выходному IP через тот же прокси с помощью [ipwho.is](https://ipwhois.io/documentation). Если сервис временно недоступен, успешная проверка IP сохраняется, а вместо региона отображается пояснение. Флаги встроены в приложение и не требуют отдельного соединения. Используются SVG из [flag-icons](https://github.com/lipis/flag-icons) с лицензией MIT.

Поиск учитывает IP, страну и регион. Фильтр состояния прокси сочетается с папкой и статусом профиля. **Выбрать найденные** выделяет строки по текущим фильтрам на всех страницах; количество выбранных вне фильтра видно над таблицей. **Проверить прокси** проверяет выбранные строки в фоне с общим итогом. Ошибка запуска видна в строке профиля и уведомлении, а завершение или ошибка переноса — в уведомлении с доступом к отчёту.

Приложение отслеживает процесс каждого запущенного Chrome независимо от автовхода в X. После закрытия последнего окна профиль получает статус «Закрыт», счётчик запущенных профилей уменьшается, а кнопка меняется на «Запустить». Закрытие одной вкладки при оставшихся окнах не закрывает профиль; медленный ответ браузера также не считается его завершением.

В комплектном Chrome исходно выбран провайдер `No Search` с адресом `http://%s`. При запуске профиля XAnty заменяет этот режим на Google, поэтому ввод `delivery` открывает поиск. Настройка сохраняется в профиле. Уже выбранный рабочий поисковик сохраняется. Исправление применяется к существующим профилям при их следующем запуске.

## Передача профилей другому пользователю

Кнопка копирования в строке создаёт пакет одного профиля. Через **Передать профили** можно экспортировать выбранные профили или сразу все, независимо от текущей папки, поиска и страницы таблицы. Перед экспортом закройте передаваемые браузеры.

Результат — файл `.xanty`. Передайте его получателю, который откроет **Передать профили → Получить профили из файла** в такой же версии XAnty. Пакет содержит настройки, логины, прокси, cookies всех сайтов и файлы профиля Chrome, включая local storage и установленные в каталоге профиля расширения. Браузерный кэш и временные блокировки не включаются. Папки сохраняются; при совпадении имени можно создать копию или пропустить существующий профиль. Существующие данные не перезаписываются, файлы сначала проверяются и подготавливаются во временной папке.

Для переноса cookies между компьютерами XAnty сохраняет их отдельно от шифрования Windows и восстанавливает через Chrome DevTools Protocol. Старые закрытые профили с обычным шифрованием Chrome также поддерживаются. Если приложение не смогло расшифровать часть cookies, отчёт предложит открыть и закрыть профиль в XAnty перед повторным экспортом. Сохранённые пароли Chrome, отдельные ключи расширений и некоторые сессии сайтов могут быть привязаны к исходному компьютеру и потребовать повторного входа.

Файл содержит сессии и реквизиты прокси: передавайте его только получателю профилей. Сам XAnty не отправляет пакет другим людям. Копия для скачивания удаляется из временной папки после закрытия приложения; сохранённый пользователем файл остаётся на диске.

## Автовход в X

В строке профиля есть тумблер X auto-login; для нескольких профилей есть кнопки включения и выключения и поле в Bulk edit. При выключенном тумблере браузер открывает пустую вкладку и не пытается войти в X. При включённом использует сохранённую сессию, затем токен или пароль. Настройка применяется при следующем открытии профиля. У старых аккаунтов без этого поля сохраняется прежний автоматический вход; новые профили и импортированные аккаунты начинают с выключенным автовходом.

## Управление профилями

Для профиля доступны статусы **Активен**, **Новый**, **На проверке**, **Не используется**. Они задаются в строке, редакторе и массовом редактировании независимо от состояния браузера. Звёздочка закрепляет избранные профили в начале списка. Поиск охватывает название, внутреннее имя, постоянный номер, заметки, теги, прокси и его географию. Теги редактируются через запятую.

Последний запуск показывает дату и время открытия, время работы — суммарные часы. Эти данные сохраняются между запусками; отсчёт начинается после обновления. При аварийном завершении сохраняется последняя контрольная точка (раз в 30 секунд). Двойной клик по названию или F2 меняет отображаемое имя. Кнопка **Колонки** позволяет скрыть поля и изменить их порядок стрелками; выбор сохраняется.

Удаление закрытого профиля переносит его в **Корзину** вместе с настройками, сохраняя файлы браузера и cookies. При удалении и в корзине можно выбрать срок: от 1 до 3650 дней или 0 для бессрочного хранения; исходно 30 дней. Срок считается с удаления. Просроченные профили очищаются при запуске и раз в минуту, пока XAnty работает. До окончательного удаления профиль можно восстановить. **Удалить навсегда** также удаляет его файлы Chrome и cookies.

**История изменений** доступна для всех профилей и в меню отдельного профиля. Она хранит время, пользователя Windows и предыдущие/новые настройки, включая массовые изменения, корзину и восстановление. Пароли и токены скрыты, из прокси удаляются реквизиты доступа. История начинается после обновления; прежних событий в ней нет.

## Вкладки, расширения и инструменты браузера

Версия `2026.11.22.7` добавляет пункты 10–19. Новые `.xanty`-пакеты содержат SHA-256 для настроек, cookies и файлов; импорт проверяет содержимое до записи профилей. Старые пакеты поддерживаются с явным предупреждением об отсутствии контрольных сумм. Контрольные суммы обнаруживают повреждение, но не подтверждают автора пакета.

В редакторе профиля находятся **Восстанавливать открытые вкладки**, **Набор расширений** и **Текст значка**. Вкладки восстанавливаются средствами Chrome и из снимка адресов без повторного добавления уже открытых страниц. Проверка прокси работает в служебном процессе расширения без открытия или переключения вкладок. Снимки адресов обновляются каждые 10 секунд; формы и оперативное состояние JavaScript не переносятся.

**Настройки браузеров** над таблицей управляют автосохранением сессий (cookies всех сайтов и вкладки, исходно каждые 60 секунд, допустимо 30–3600). Chrome самостоятельно сохраняет локальное хранилище. Начиная с `2026.11.23.2`, цветные обводки окон полностью удалены вместе с их настройками.

Там же можно создавать наборы из локальных папок распакованных расширений Chrome **Manifest V3**. Укажите по одному полному пути к папке с `manifest.json` в строке. При создании профиля выбранный набор копируется внутрь его каталога и переносится вместе с пакетом. Скачивания из магазина нет. Выбор **Без набора** отключает загрузку управляемого набора, сохраняя его файлы. [Требования Chrome к Manifest V3](https://developer.chrome.com/docs/extensions/develop/migrate/mv2-deprecation-timeline).

В меню строки доступны **Cookies: просмотр и вставка**, **Сохранить сессию сейчас**, **Открыть папку профиля**, **Очистить только кэш** и **Проверка WebRTC / DNS**. Cookies всех сайтов, включая HttpOnly, видны в JSON; для закрытого профиля можно вставить JSON/Netscape или загрузить файл. Они объединяются с сохранёнными и применяются при следующем открытии независимо от автовхода в X. Очистка закрытого профиля удаляет только известные каталоги кэша, сохраняя cookies, вкладки, расширения и локальное хранилище.

Диагностика работает внутри выбранного Chrome через ipify, Google STUN и [API dnsleak.dev](https://dnsleak.dev/api), показывает IP, публичные WebRTC-кандидаты и DNS-резолверы. Сервисы получают тестовые сетевые запросы. Ошибка или неполный тест не считаются успешной проверкой; различия операторов/географии DNS сами по себе не доказывают утечку.

Каталог профиля защищён системной блокировкой от конфликтующих запусков и операций с файлами. Одну рабочую папку может изменять только один экземпляр XAnty; разные рабочие папки могут использоваться отдельно. При завершении программа дожидается своих сохранений и закрытий браузеров, не закрывая чужие Chrome/ChromeDriver.

## Инструменты рабочего пространства (20–32)

Версия `2026.11.22.8` добавляет раздел **Инструменты**. Размер каждого профиля измеряется в фоне без общего ядра Chromium; колонки **Размер профиля** и **Напоминание** включаются в настройке колонок. В разделе места на диске доступны повторный замер, очистка кэша выбранных закрытых профилей и предварительный просмотр устаревших служебных файлов. Удаляются только распознанные временные файлы старше семи дней; профили, резервные копии и файл отката приложения сохраняются.

**Версии Chromium** скачивает официальные пары Chrome for Testing / ChromeDriver одной версии и позволяет выбрать общую пару для всех профилей. Каталоги данных профилей остаются отдельными. Установка и выбор — разные действия; для переключения и удаления сборки нужно закрыть профили. Исходная сборка `Bro / Drivers` сохраняется. Проверяются HTTPS-источник, структура и CRC архивов, версии обоих EXE; подписанные контрольные суммы Google в этом каталоге отсутствуют.

В редакторе профиля можно отключать изображения, аудио/видео и веб-шрифты, включать локальные предупреждения о подозрительных адресах, отмечать профиль важным и задавать напоминание. Предупреждения распознают структурно подозрительные адреса и дополняют Chrome Safe Browsing; они не обнаруживают весь фишинг. Важные и избранные профили требуют ввода `DELETE` при ручном переносе в корзину и окончательном удалении. Заданный при переносе срок автоматического удаления продолжает действовать.

**Локальные резервные копии** включаются после выбора папки на локальном диске. Задаются интервал и число хранимых копий. Запись проверяется и публикуется атомарно; удаляются только старые копии этого рабочего пространства после успешного сохранения новой. Копии содержат секреты и сессии. Автоматическое копирование работает при запущенном XAnty и закрытых профилях, иначе ожидает освобождения файлов.

Экспорт по умолчанию переносит названия, прокси и их реквизиты, все настройки профиля, cookies, вкладки и файлы браузера. Режим **Только шаблон без данных профиля** включается вручную: он исключает названия, папки, заметки, прокси, пароли, токены, cookies и файлы браузера. **Наборы окон** сохраняют точный состав профилей по постоянным идентификаторам; переименование не нарушает набор. Перед закрытием окон вне набора запрашивается подтверждение. Отсутствующий или удалённый в корзину участник требует исправить набор.

Напоминания сохраняются с часовым поясом, отображаются в местном времени и уведомляют внутри XAnty при наступлении срока либо следующем запуске. Панель **Ошибки** показывает причины ошибок браузера/прокси и действия для исправления; реквизиты доступа скрываются.

После обновления при запуске показываются только изменения установленной версии. Предыдущие выпуски доступны без интернета через **Настройки XAnty → История обновлений**. Настройки открываются кнопкой с шестерёнкой в левом меню.

## Настольное приложение Windows

Панель XAnty открывается в собственном окне WebView2. Управляемые профили по-прежнему запускаются в отдельных процессах Chrome.

Начиная с `2026.11.23.1`, **Esc** скрывает окно XAnty в область уведомлений Windows. Профили, автосохранение, напоминания и фоновые задачи продолжают работать. Если открыт диалог или меню строки, первое нажатие Esc закрывает его. Esc внутри отдельного Chrome не скрывает XAnty. Двойной клик по значку либо пункт **Открыть** возвращает окно; правый клик → **Выход** полностью завершает программу с обычным сохранением и закрытием её профилей. Крестик окна и кнопка выхода продолжают завершать приложение. Если значок недоступен, окно остаётся открытым.

В версии `2026.11.23.1` устранено принудительное отключение GPU в профилях. Chrome сам выбирает поддерживаемое аппаратное ускорение. В версии `2026.11.23.2` полностью удалены дополнительные цветные рамки окон.

В `2026.11.23.2` каждый профиль получает отдельную группу на панели задач и значок с текстом внутри изображения. Короткие названия используются целиком; для длинных автоматически выбирается сокращение с номером профиля. В поле **Текст значка** можно задать свою подпись до восьми символов, например `Раб12`. Текст располагается в одну или две строки. Полное название отображается в заголовке окна и меню профиля Chrome, а также по нажатию закреплённого значка профиля в панели расширений. Значок не читает и не изменяет содержимое сайтов. Настройки группировки панели задач Windows не меняются. Название и значок обновляются при следующем открытии профиля.

Проверка прокси при запуске использует запрос из самого Chrome и проверяет соединение с указанным прокси. Разные выходные IP у вращающихся прокси допускаются. Если первый IP-сервис вернул ошибку или неполный ответ, используется запасной сервис через тот же прокси; ошибки авторизации остаются ошибками. Вкладки пользователя не участвуют в проверке. Однократное исправление встроенного `No Search` выполняется в фоновой странице без переключения фокуса и сохраняет отметку об успехе для текущей основной версии Chrome; рабочий выбранный поисковик сохраняется.

Окно со страницей загрузки создаётся до импорта сервиса и обработки профилей. Подготовка выполняется в фоне, поэтому окно можно перемещать и закрывать во время запуска. При ошибке отображается причина; время этапов и ошибки сохраняются в `%LOCALAPPDATA%\XAnty\startup.log`. Значок EXE, окна и интерфейса обновлён по предоставленному изображению.

Для запуска из исходников: `python -m pip install -r requirements.txt`, затем `python main.py`. Если WebView2 Runtime отсутствует, установите его с сайта Microsoft. При первом запуске выберите рабочую папку с `Bro/chrome.exe` и `Drivers/chromedriver.exe`.

Для сборки `.exe`: `python -m pip install -r requirements-build.txt`, затем `python tools/build_windows.py`. Результат — `dist/XAnty/XAnty.exe` вместе с соседними файлами; папку `dist/XAnty` переносите целиком. Сборку нужно выполнять на Windows. Настройки собранного приложения хранятся в `%LOCALAPPDATA%\XAnty`, а папка с аккаунтами и профилями выбирается на экране первого запуска.

Для сборки в один файл: `python tools/build_windows.py --onefile`. Результат — `dist/XAnty.exe`; Python на компьютере для запуска не нужен. Браузер `Bro/chrome.exe` и драйвер `Drivers/chromedriver.exe` должны находиться в выбранной рабочей папке.

Для сборки обновления при открытой предыдущей версии: `python tools/build_windows.py --onefile --dist-dir dist/update`.

## Установка и обновления через GitHub

Скачайте `XAnty-Setup.exe` из [последнего релиза](https://github.com/mur3r/XAnty/releases/latest). Установщик ставит программу для текущего пользователя, официальные Chrome for Testing / ChromeDriver и при необходимости WebView2. Python не требуется. Существующие профили и настройки сохраняются.

При каждом запуске программа проверяет GitHub до открытия рабочего пространства. Новая версия скачивается, проверяется по SHA-256, устанавливается и запускается автоматически. Без сети или при ошибке скачивания открывается установленная версия. Если новая программа не запускается, выполняется откат; повторная неудачная установка не вызывает бесконечные перезапуски.

Обычная загрузка изменений в `main` автоматически запускает тесты, назначение новой версии, сборку EXE/установщика и публикацию полного релиза. [Подробности установки и обновлений](docs/github-updates.md).

## Локальные данные и Git

В репозиторий входят исходники и демонстрационные данные. `accounts.json`, `folders.json`, cookies, профили браузеров, реквизиты прокси, логи, архивы и локальные настройки исключены через `.gitignore` и остаются на компьютере. Перед публикацией исходников выполните `python tools/publish_github.py --check`; проверка также ищет значения учётных данных из локального `accounts.json`. Не добавляйте личные файлы принудительно через `git add -f`.
